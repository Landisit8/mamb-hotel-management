# MAMB Hotel Management

Software gestionale alberghiero sviluppato principalmente in Java.

## Obiettivo
Realizzare un gestionale modulare per:
- prenotazioni
- check-in / check-out
- camere
- clienti
- pagamenti
- reportistica

## Stack iniziale
- Java
- Spring Boot
- PostgreSQL
- GitHub
- Codex

## Stato
Fase 0: impostazione repository, documentazione e architettura iniziale.
